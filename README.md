# Roadmap Generator

一个通用的 Roadmap 生成器工具，允许非技术人员通过简单的表单配置，自动生成包含里程碑、待办事项、依赖关系可视化的路线图网页或图片。

## 功能特性

- 📝 **可视化编辑器**：左侧配置面板，右侧实时预览
- 🎨 **多主题支持**：4 种预设主题（默认、科技蓝、活力橙、暗夜黑）
- 📋 **灵活的内容块**：支持标准清单、警告块、信息块、待定块、复杂列表、分组标题
- 🎯 **里程碑管理**：完整的 CRUD 操作，支持拖拽排序
- 💾 **数据持久化**：自动保存到 LocalStorage
- 📤 **多种导出格式**：
  - HTML：自包含的单文件 HTML
  - PNG：高分辨率图片导出
  - JSON：配置文件导入/导出
- 📱 **响应式设计**：支持桌面端和移动端

## 技术栈

- React 18
- Vite
- Tailwind CSS
- FontAwesome 6.0
- @dnd-kit (拖拽排序)
- html2canvas (图片导出)

## 使用指南

### 1. 全局设置

- **项目标题**：设置路线图的主标题
- **副标题**：设置副标题或描述
- **主题选择**：从 4 种预设主题中选择
- **状态图例**：自定义状态图例的标签和颜色

### 2. 里程碑管理

- 点击"添加里程碑"创建新的里程碑
- 每个里程碑包含：
  - 日期/时间段
  - 标题和描述
  - 状态（规划中/进行中/已上线/关键路径/迭代开发）
  - 图标
  - 多个内容块

### 3. 内容块类型

#### 标准清单 (List)
- 带图标的列表项
- 适用于功能列表、任务清单等

#### 警告/依赖块 (Alert)
- 支持警告、危险、信息三种变体
- 适用于前置依赖、注意事项等

#### 时间跨度/说明块 (Info)
- 包含日期、徽章、描述
- 适用于时间节点说明

#### 待定/风险块 (TBD)
- 适用于待确认的需求、风险项

#### 复杂列表项 (Complex List)
- 每个项包含图标、标题、描述
- 适用于功能详细说明

#### 分组标题 (Section)
- 用于内容分组

### 4. 导出功能

- **导出 HTML**：生成自包含的 HTML 文件，可直接部署或分享
- **导出 PNG**：将预览区域导出为高分辨率图片
- **导出 JSON**：保存当前配置，便于后续编辑
- **导入 JSON**：从文件导入之前的配置

### 5. 拖拽排序

在编辑器面板中，点击里程碑左侧的拖拽图标，可以拖拽调整里程碑的顺序。

## 数据格式

路线图数据采用 JSON 格式，结构如下：

```json
{
  "meta": {
    "title": "产品开发路线图",
    "subtitle": "Product Development Roadmap 2026 Q1",
    "theme": "default",
    "legend": [
      { "label": "内测阶段", "color": "amber" }
    ]
  },
  "milestones": [
    {
      "id": "m1",
      "date": "2026.01.28",
      "title": "用户内测开启",
      "description": "Internal Beta Testing",
      "status": "warning",
      "icon": "fa-flask",
      "blocks": [...]
    }
  ]
}
```
